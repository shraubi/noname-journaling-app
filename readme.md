# Unsaid

A private, model-free journaling experiment inspired by dangerous writing apps.

Write without interruption. When you stop for ten seconds, Unsaid asks where
the thought became stuck: in the facts, the feeling, the desire, the admission,
or what comes next. It then offers one hand-written question and disappears as
soon as you continue typing.

The draft is stored only in the browser. There is no account, backend, content
analysis, local language model, or cloud API.

## Run locally

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed in the terminal. Use `npm run build` to verify a
production build.
